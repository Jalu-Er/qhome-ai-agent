# Draft Deskripsi Submission

QHome AI Agent adalah sistem multi-agent AI untuk membantu triage customer support pada konteks retail home improvement seperti QHome Mart. Sistem ini menerima pertanyaan atau komplain pelanggan, kemudian menjalankan lima agent spesialis secara berurutan: Intent Classifier Agent untuk membaca intent dan kategori masalah, Knowledge Retrieval Agent untuk mengambil policy atau FAQ yang relevan, Solution Planner Agent untuk menyusun langkah penyelesaian, Priority & Escalation Agent untuk menilai SLA dan kebutuhan eskalasi, serta QA & Final Response Agent untuk memastikan jawaban final konsisten dan siap dikirim ke pelanggan.

Nilai unik project ini ada pada transparansi dan reproducibility. Setiap interaksi agent dicatat ke log JSONL, output akhir disimpan dalam JSON terstruktur, dan sistem juga menghasilkan report Markdown yang mudah ditinjau. Dengan pendekatan ini, tim support dapat memproses ticket lebih cepat, menjaga konsistensi jawaban, dan memprioritaskan kasus yang berisiko terhadap kepuasan pelanggan atau biaya operasional. Project mendukung live mode menggunakan SumoPod AI API yang kompatibel dengan OpenAI, serta mock mode agar demo tetap dapat dijalankan tanpa API key.
